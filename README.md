# Kreg Lite

A self-hosted uptime monitor. Add a URL, the server checks it every few seconds, saves every
result, opens an incident after 3 failures in a row, and shows uptime on a public status page.

**Stack:** Node.js, Express, Prisma, PostgreSQL, JWT. Optional React frontend.

## How to contribute

1. Fork this repo (or clone it if you're a collaborator).
2. Make a branch for your task, e.g. `kl-07-register`.
3. Open a pull request with the task ID in the title, e.g. `KL-07: register route`.
   Heartbeat marks the task done when the PR is merged.
